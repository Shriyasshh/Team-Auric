About the MST Blockchain  
The MST Blockchain challenges builders to create innovative, practical, and scalable products powered 
by MST Blockchain. Go beyond traditional DApps, basic wallet integrations, and projects that simply bolt 
blockchain on as a feature 
Track Requirements - Mandatory 
All five requirements below are mandatory for prize eligibility. Read them carefully before building. 
 
1.  MST Blockchain Usage  
●​ Your project must use MST Blockchain as a meaningful, integral part of the product. 
●​ A simple wallet connection or single isolated transaction is not sufficient. 
 
2.  MST Testnet Deployment   
Every project must be deployed on MST Testnet before submission.  
Your submission must include: 
●​   MST Testnet contract address 
●​   At least one verifiable MST Testnet transaction hash 
●​   A working application or demo link (wherever applicable)​
 
3.  Public GitHub Repository  
Every team must submit a public GitHub repository with the project's full source code, 
including: 
Smart contracts + frontend / backend code 
README with MST integration details, contract addresses, and setup instructions

4.  BridgeKey Wallet Integration - Strongly Recommended 
BridgeKey is the official non-custodial wallet for MST Blockchain. 
Teams are strongly encouraged to integrate BridgeKey for wallet connection, network 
switching, 
and smart contract signing in their DApps.

5.  Working Product + On-Chain Proof 
A working deployed application is strongly preferred over mockups. 
Projects that judges can interact with and test will have a significant advantage. 
Your project must have at least one verifiable MST Testnet transaction demonstrating core 
functionality.

Judging Criteria 
 
What Wins at This Hackathon 
Problem  →  Solution  →  Meaningful MST Usage  →  Working Product  →  Testnet Deployment  →  
Scale 
 Strong ideas, meaningful blockchain integration, and solid execution is important. 
 
Use of AI & Originality Policy 
AI coding assistants, AI agents, MCP, Vibe Kit, SDKs, open-source libraries, and other developer tools 
are all permitted. Every team must fully understand the code they submit and be ready to explain their 
architecture, MST integration, and implementation decisions to judges. 
 
⚠  Projects found to be substantially copied, plagiarised, or using fake / misleading deployment 
or transaction data may be disqualified from all prizes.​
